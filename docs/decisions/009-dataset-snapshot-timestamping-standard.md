# ADR 009: Dataset Snapshot Ingestion & Timestamping Standard

* **Status**: Accepted
* **Date**: 2026-09-01
* **Category**: Diátaxis Explanation / Architectural Decision Record (ADR)
* **Domain**: Dataset Ingestion, File Naming & Temporal Versioning
* **Updates / Rectifies**: [ADR 003](./003-src-package-and-dataset-architecture.md)

---

## 1. Context & Problem Statement

Raw provider model catalogs fetched during stage 01 ingestion were previously timestamped using ambiguous two-digit date formats (`<provider>-models-MMDDYY.json`, e.g. `featherless-models-083126.json`).

This created three concrete problems:
1. **Alphabetical Sorting Inversion**: Standard directory listings (`ls`) sort alphabetically rather than chronologically across months or year rollovers.
2. **Intraday Collision Risk**: Re-fetching or running scheduled cron ingests multiple times per day resulted in silent overwrites unless an hour/minute component was present.
3. **Inconsistent Provider Hyphenation**: Multi-word provider names (such as NVIDIA NIM) were intermittently formatted, creating casing and separation inconsistencies.

---

## 2. Decision: Strict `YYYYMMDD-HHMM` Timestamping Grammar

We mandate a single, strict naming grammar for all raw dataset snapshots generated by `01_ingestion` and stored in `datasets/`:

$$\texttt{datasets/<provider>-models-YYYYMMDD-HHMM.json}$$

### Architectural Rules:

1. **Mandatory `YYYYMMDD-HHMM` Timestamp**:
   * Timestamps must strictly follow 4-digit year, 2-digit month, 2-digit day, a hyphen, and 2-digit 24-hour time with 2-digit minute (`%Y%m%d-%H%M`).
   * Date-only timestamps (`YYYYMMDD`) are strictly prohibited to prevent intraday collisions.
   * Historical/sample fixtures without an exact capture minute use `0000` as the default time component (e.g. `20260831-0000`).

2. **Kebab-Case Provider Normalization**:
   * All provider names must be normalized to lowercase `kebab-case` before interpolation.
   * Multi-word providers become hyphenated strings (e.g. `nvidia nim` $\rightarrow$ `nvidia-nim-models-20260831-0000.json`).

3. **Opt-Out Ephemeral Ingestion Target**:
   * When permanent dataset vaulting is disabled by the user (`save_model_data: false`), `01_ingestion` writes to `models-list.json` in the root workspace.
   * `models-list.json` is strictly an ephemeral scratchpad overwritten on every run.

---

## 3. Consequences

* **Positive**: Natural alphabetical sorting in file explorers and object storage guarantees exact chronological ordering.
* **Positive**: Intraday ingestion jobs never collide or overwrite previous snapshots.
* **Positive**: Eliminates format ambiguity across all provider ingestion pipelines.
* **Negative**: Existing sample dataset files and test fixtures must adhere strictly to the `YYYYMMDD-HHMM` format.
